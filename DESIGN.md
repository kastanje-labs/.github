# Kastanje Labs GitHub profile

Reuse the public pixel chestnut from kastanje-labs/landing-page and the simple mark-plus-wordmark composition from arcitai/.github. The audience is a visitor assessing the project and its public code. Present Kastanje as an experimental AI infrastructure project in development.

Use the existing light palette: panel #e8eff8, ink #0b1428 and muted #4b627c. Geist Pixel Square owns the wordmark; Geist Sans owns supporting text. The banner is 1200 × 300 px, with generous spacing and a short two-line description. The avatar is 512 × 512 px, with a centered chestnut and safe margins for a circular crop. No new mascot or generated scene.

The organisation README places the banner first, followed by the project purpose, three public repositories and a clear prototype status. The platform source stays private. Do not promise a launch date or production service. Profile images have meaningful alt text; GitHub scales the banner responsively. HTML and original SVG are editable sources; PNG files are publication derivatives.

Source references: arcitai/.github/profile/assets/banner.html; kastanje-labs/landing-page/public/kastanje-mark.svg; kastanje-labs/landing-page/src/design-tokens.css. Fonts retain their existing SIL Open Font License.
