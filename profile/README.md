# Kastanje Labs

Kastanje is an experimental AI infrastructure project by [Gustav Anderson](https://github.com/gustavonline). I explore how coding agents can connect to a shared platform through small, focused integrations.

The public work includes connections for VS Code and Codex, plus the Kastanje website. The platform is a separate private prototype and is still in development.

## Explore the work

| Repository | Purpose |
| --- | --- |
| [VS Code extension](https://github.com/kastanje-labs/vscode-extension) | Connect the native VS Code coding agent to Kastanje |
| [Codex plugin](https://github.com/kastanje-labs/codex-plugin) | Connect and configure Codex for the hosted Kastanje platform |
| [Website](https://github.com/kastanje-labs/landing-page) | Public website, manifest and visual identity |

## Project status

This is work in progress. The repositories document what has been built, how to run it and the current limits. They are not a promise of a production service or a launch date.
